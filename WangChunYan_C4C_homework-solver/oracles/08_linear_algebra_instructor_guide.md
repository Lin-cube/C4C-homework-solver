## 1. 线性代数证明题的四大范式（→ 证明模板）

### 范式 A：从"已知等式"两侧同时施加一个保持等式的运算
> **适用**：涉及 $\det$、$A^{-1}$、转置的恒等式证明。

**标准四步**：
1. **Given**：写出已知条件（如 $A$ 可逆，$AA^{-1}=I$）；
2. **Act**：对等式**两侧同时**施加同一个可逆运算（取行列式/取转置/左乘）；
3. **Simplify**：用性质化简到目标形式的关键中间式；
4. **Conclude**：回代并注明前提（如 $\det A\neq0$）。

**范例（本次作业 P9）**：证明 $\det(A^{-1})=1/\det A$
```
Given : AA^{-1} = I
Act   : det(AA^{-1}) = det(I)
Simplify: det(A)·det(A^{-1}) = 1
Conclude: det(A) ≠ 0 ⇒ det(A^{-1}) = 1/det(A)   ∎
```

### 范式 B：线性组合零化法（证明线性无关）
> **适用**：证明特征向量族、向量组线性无关。

**标准三步**：设 $\sum c_i v_i=0$ → 施加算子/左乘 $A$ 得到第二式 → 联立解出全部 $c_i=0$。

### 范式 C：反例法（证伪命题）
> **适用**："$X$ 是否总是成立？"型判断题。
> 只需给出一个满足前提但违反结论的**具体实例**，并逐步验证。

### 范式 D：维数/秩的夹逼（rank-nullity）
> **适用**：涉及秩、零空间维数、解空间结构的证明。
> 用 $\operatorname{rank}A+\dim\ker A=n$ 作为桥梁，配合 $\le$ / $\ge$ 双向夹逼。

## 2. 评分 Rubric（阅卷人视角）

| 得分点 | 权重 | 说明 |
|---|---|---|
| 正确识别可用的定理/性质 | 30% | 用错定理直接零分 |
| 推导链条完整（无跳步） | 40% | 关键中间式必须写出 |
| 前提条件检查（如 $\det\neq0$） | 20% | 漏掉前提扣分 |
| 规范结尾（$\blacksquare$、结论明确） | 10% | 表述分 |

> **对求解器的要求**：证明模板必须显式包含"前提检查"与"关键中间式"两步——
> 这正是 `llm_engine.py` 中离线模板每条都带"前提句 + 中间式 + 结论句"的原因。

## 3. 考试陷阱（命题人常用）

| 陷阱 | 表现 | 破解 |
|---|---|---|
| 用 $n$ 阶泛指 | "证明：若 $n$ 阶方阵 $A$ 可逆……" | 证明须对任意 $n$ 成立，不能只验 2×2 |
| 混入 $\det(A+B)$ | 诱导误用线性 | 牢记行列式非线性 |
| 特征值重复 | 重根时要求"全部线性无关特征向量" | 输出基础解系并注明重数 |
| "判断是否可逆"型 | 只答"可逆"不答 $\det$ | 必须给出 $\det$ 值作为依据 |
| 等价形式 | 答案可能是 $\cosh x$ 或 $\frac{e^x+e^{-x}}2$ | 阅卷接受**代数等价**形式 |

## 4. 可接受的等价答案（→ 求解器归一化策略）

| 题 | 答案形式 A | 答案形式 B | 是否等价 |
|---|---|---|---|
| P7 | $y=\cosh x$ | $y=\frac{e^x+e^{-x}}{2}$ | ✓ |
| P8 | $y=(2-e^x)e^x$ | $y=2e^x-e^{2x}$ | ✓ |
| P2 | $\begin{bmatrix}1&-1\\-1&2\end{bmatrix}$ | $\frac{1}{1}\begin{bmatrix}1&-1\\-1&2\end{bmatrix}$ | ✓ |
| P9 | $\det(A^{-1})=\frac{1}{\det A}$ | $\det(A)\det(A^{-1})=1$ | ✓（同一命题） |

> **对核验器的要求**：核验不能做字符串比对，必须做**代数等价判定**
> （`simplify(a-b)==0`），这正是 `verify.py` 的做法。
